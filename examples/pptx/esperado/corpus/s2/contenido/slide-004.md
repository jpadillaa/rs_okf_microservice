## Notas del presentador

RAG es una arquitectura que combina un LLM con un sistema de recuperación de información externo y dinámico. En lugar de depender únicamente del conocimiento estático, el LLM se alimenta con fragmentos de información factual y relevante recuperados de una base de conocimiento autorizada. Estas bases de conocimiento pueden ser cualquier colección de datos: documentos internos de una empresa, manuales de productos, artículos de una base de datos científica, páginas web o registros de una base de datos.
