GUÍA DOCENTE

Defina la Generación Aumentada por Recuperación (RAG) como el uso de información recuperada desde fuentes externas para sustentar una respuesta generada. Recorra las alternativas de la lectura: un documento conocido que cabe en el contexto puede proporcionarse directamente; un dato concreto puede obtenerse mediante una API o base de datos autorizada; localizar documentos puede resolverse con un buscador.
