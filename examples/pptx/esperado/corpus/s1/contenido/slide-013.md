## Notas del presentador

GUÍA DOCENTE

Defina la Generación Aumentada por Recuperación (RAG) como el uso de información recuperada desde fuentes externas para sustentar una respuesta generada. Recorra las alternativas de la lectura: un documento conocido que cabe en el contexto puede proporcionarse directamente; un dato concreto puede obtenerse mediante una API o base de datos autorizada; localizar documentos puede resolverse con un buscador. RAG resulta pertinente cuando hay que seleccionar información entre fuentes y utilizarla para responder.

Regrese al caso universitario y explique que la consulta puede requerir combinar disposiciones generales y específicas para el nivel académico del estudiante. Esa dependencia de información justifica estudiar recuperación. Aclare que las soluciones pueden combinarse y que RAG puede usar búsqueda léxica, semántica o estructurada. La decisión de incorporar recuperación introduce componentes, costos, latencia y modos de fallo que deben justificarse por la tarea.
