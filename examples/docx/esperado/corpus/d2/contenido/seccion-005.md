# Paso No. 3 - Análisis comparativo de costo-beneficio entre APIs de IA generativa y despliegue on-premise

<!-- okf-source-span: b-31 -->
Con el presupuesto estimado en el paso anterior, se debe proyectar la cantidad de tokens que podrían adquirirse mediante las APIs de OpenAI, Google Gemini y Claude, con el propósito de comparar esta alternativa frente a la inversión requerida para una implementación on-premise.

<!-- okf-source-span: b-32 -->
El análisis debe considerar, para cada fabricante, los modelos más representativos y pertinentes para este ejercicio, incluyendo tanto versiones de propósito general como variantes orientadas a razonamiento avanzado, cuando aplique. Los tokens estimados deben distribuirse a lo largo de un periodo de tres años, definido como horizonte de amortización de los componentes de TI estimados previamente. Esto permitirá desarrollar una comparación consistente entre el costo por uso de APIs y la inversión inicial, junto con los costos de mantenimiento asociados al despliegue local de la plataforma.

<!-- okf-source-span: b-33 -->
La evaluación debe incorporar de manera explícita la estructura de costos de cada API, incluyendo el costo de los tokens de entrada y de salida, así como otros elementos tarifarios relevantes que afecten la estimación económica. A partir de ello, se debe realizar un contraste comparativo entre fabricantes para identificar la alternativa con mejor relación costo-beneficio, teniendo en cuenta no solo el precio, sino también las capacidades del modelo, sus restricciones de uso, el acceso a funciones avanzadas y la conveniencia institucional de cada opción.
