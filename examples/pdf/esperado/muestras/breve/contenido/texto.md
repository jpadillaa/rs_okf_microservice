# Préstamo de equipos audiovisuales

La biblioteca presta cámaras, micrófonos y trípodes a estudiantes y profesores para actividades académicas. El préstamo dura como máximo tres días hábiles y se renueva una sola vez si nadie más ha reservado el equipo.

Para solicitar un equipo se presenta el carné vigente en el mostrador de servicios. Antes de entregarlo, el personal revisa con el usuario que el equipo funcione y que tenga todos sus accesorios.

- Las reservas se hacen con dos días de anticipación.
- Los daños se reportan el mismo día de la devolución.
- Las devoluciones tardías suspenden el servicio una semana.
